## 处理步骤
1. 核对订单商品、规格、色号与用户实收（有图片时以图片核验结果为准）。
2. 确认错发后先致歉，不要求用户先寄回再补发；无需用户承担运费。
3. 创建优先补发工单，告知补发时效（以工单系统返回为准，不得自行承诺）。
4. 错发商品处理：说明是否需要寄回及回寄方式。
5. 创建跟进任务，补发出库后主动通知用户。

## 回复要点
- 先承认问题、再给方案，一句话说清楚“我们会怎么做、什么时候”。
- 用户多次进线时，明确说出“这次由我跟进到底”。

## 禁止
- 不得质疑用户“是不是自己拿错了”。
- 不得承诺工单系统未返回的到货时间。
