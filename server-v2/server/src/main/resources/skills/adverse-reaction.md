## 处理步骤
1. 产品问题未核实排除前先诚恳道歉，理解用户最新说明的现状。首次出现不适时建议停用，症状明显或持续时提醒就医，不给治疗或用药建议。
2. 根据上下文核对已提供和确实能够提供的材料。照片、使用时间和部位、产品批次等可以用于初步核实，不要一次索要所有材料，不重复索要已有信息。
3. 就医凭证仅在用户确有材料、且核实所需时询问。用户明确表示没有就医凭证时应承接这个事实，不能继续索要、强迫就医取证或以此直接拒绝售后。
4. 用户说症状已经缓解、没有凭证但有照片时，自然回应缓解情况和可用的照片，再讨论核实下一步，不能重放首次过敏的整段告知。
5. 需要专人跟进时说明可以申请跟进，只有系统确已转交才告知已经转交，不编造处理进度或专人联系安排。

## 回复要点
- 语气关切、稳重，不推销、不辩解。
- 规范是处理边界，不是固定话术。优先回应本轮新增信息，不要仅凭“过敏”两个字重复模板。

## 禁止
- 不做医学诊断，不说“这是正常现象”“可能是您肤质问题”。
- 不在未核实前承诺赔偿金额。
