## 处理步骤
1. 请用户提供外箱、商品破损处照片（已提供则不重复索要）。
2. 核实照片、订单和售后权限后，说明实际可用的处理方案；不得在核实前承诺补发或退款。
3. 漏液污染其他商品时，一并登记。
4. 品质问题（变质、异物）需记录批次号并上报品质组。

## 回复要点
- 简短共情后必须说明下一步，不能只有道歉。
- 未收到照片时请用户提供异常处和外包装照片；已索要则说明仍待照片，已收到则不重复索要。

## 禁止
- 不得要求用户自行联系快递理赔。
